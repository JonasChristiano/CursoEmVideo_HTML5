# Estudos de HTML5 — Curso em Vídeo

Repositório de prática realizado a partir das aulas de HTML5 do **Curso em Vídeo**, com um site demonstrativo sobre Google Glass.

## Conteúdo praticado

- Estrutura de páginas com HTML e estilos em CSS.
- Navegação entre páginas e galeria de imagens.
- Áudio, vídeo e interações simples em JavaScript.
- Construção visual de um formulário de contato.

## Visualizar

Abra `index.html` no navegador ou sirva a pasta localmente:

```bash
python3 -m http.server 8000
```

Acesse `http://localhost:8000`.

## Estado e créditos

Exercício histórico de aprendizado, baseado no material do Curso em Vídeo. O conteúdo sobre Google Glass faz parte do exemplo das aulas e não representa informações atuais sobre o produto.

O formulário é uma demonstração de interface; este repositório não implementa um serviço backend para receber mensagens. O projeto não é apresentado como produto original independente.
